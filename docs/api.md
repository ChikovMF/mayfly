# Mayfly HTTP API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | [`/api/files`](#загрузить-файл) | Загрузить файл |
| `GET` | [`/api/files/{id}`](#скачать-файл) | Скачать файл |
| `HEAD` | [`/api/files/{id}`](#получить-информацию-о-файле) | Получить информацию о файле |

Ответы `4xx` и `5xx` возвращаются в едином формате — см. [Ошибки](#ошибки).

---

## Загрузить файл

```http
POST /api/files
```

### Заголовки запроса

| Заголовок | Значение |
|---|---|
| `Content-Type` | `multipart/form-data` |

### Тело запроса

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `file` | file | Да | Загружаемый файл |
| `expiresAt` | string | Нет | Момент, после которого файл недоступен (ISO 8601, например `2026-10-09T15:00:00Z`), в будущем. Без него файл хранится бессрочно |

### Ответы

| Код | Описание |
|---|---|
| `201 Created` | Файл загружен |
| `400 Bad Request` | Некорректный запрос |
| `413 Content Too Large` | Файл слишком большой |

### Заголовки ответа `201`

| Заголовок | Описание |
|---|---|
| `Location` | Адрес файла: `/api/files/{id}` |

### Тело ответа `201`

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Идентификатор файла |
| `expiresAt` | string \| null | Момент, после которого файл недоступен (ISO 8601, UTC). `null` для бессрочного файла |

```json
{
  "id": "7KpQ2mXa9B",
  "expiresAt": "2026-10-09T15:00:00Z"
}
```

## Скачать файл

```http
GET /api/files/{id}
```

### Параметры пути

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `id` | string | Да | Идентификатор файла |

### Ответы

| Код | Описание |
|---|---|
| `200 OK` | Содержимое файла |
| `404 Not Found` | Файл не найден |

### Заголовки ответа `200`

| Заголовок | Описание |
|---|---|
| `Content-Type` | MIME-тип файла |
| `Content-Length` | Размер файла в байтах |
| `Content-Disposition` | `attachment` с именем файла |
| `Mayfly-Expires-At` | Момент, после которого файл недоступен (ISO 8601, UTC). Только для файлов с ограниченным сроком хранения |

## Ошибки

Ответы `4xx` и `5xx` имеют формат Problem Details ([RFC 9457](https://www.rfc-editor.org/rfc/rfc9457)).

Ответ на `HEAD` не содержит тела, только код ответа.

### Заголовки ответа

| Заголовок | Значение |
|---|---|
| `Content-Type` | `application/problem+json` |

### Тело ответа

| Поле | Тип | Описание |
|---|---|---|
| `type` | string | URI типа ошибки |
| `title` | string | Краткое описание типа ошибки |
| `status` | integer | HTTP-код ответа |
| `detail` | string | Описание конкретной ошибки. Необязательное |
| `traceId` | string | Идентификатор запроса |
| `errors` | object | Ошибки по полям запроса: имя поля → массив сообщений (string[]). Только для `400 Bad Request` |

### Примеры

`400 Bad Request`

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.1",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "file": ["The file field is required."]
  },
  "traceId": "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01"
}
```

`404 Not Found`

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.5",
  "title": "Not Found",
  "status": 404,
  "traceId": "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01"
}
```

`500 Internal Server Error`

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.6.1",
  "title": "An error occurred while processing your request.",
  "status": 500,
  "traceId": "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01"
}
```
