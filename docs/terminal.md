# Консольный клиент Mayfly

```
mayfly <команда> [аргументы] [опции]
```

| Команда | Описание |
|---|---|
| [`upload <path>`](#upload) | Загрузить файл |
| [`info <id>`](#info) | Показать информацию о файле |
| [`download <id>`](#download) | Скачать файл |
| [`config set server <url>`](#config-set-server) | Сохранить адрес сервера |
| [`config get server`](#config-get-server) | Показать сохранённый адрес сервера |
| [`completion <shell>`](#completion) | Вывести скрипт автодополнения для оболочки |

### Общие опции

| Опция | Описание |
|---|---|
| `-h`, `-?`, `--help` | Показать справку по команде |
| `--version` | Показать версию |

### Адрес сервера

Команды `upload`, `info` и `download` отправляют запрос на сервер, сохранённый командой [`config set server`](#config-set-server). Опция `--server` задаёт другой адрес только для текущей команды.

### Пароль

Файл можно защитить паролем при загрузке опцией `--password` команды [`upload`](#upload). Команды `info` и `download` сами запрашивают пароль, если файл им защищён.

### Коды выхода

| Код | Описание |
|---|---|
| `0` | Команда выполнена |
| `1` | Ошибка |
| `130` | Команда прервана (Ctrl+C) |

## upload

Загрузить файл.

```
mayfly upload <path> [опции]
```

### Аргументы

| Аргумент | Описание |
|---|---|
| `path` | Путь для загрузки |

### Опции

| Опция | Описание |
|---|---|
| `-e`, `--expires-in <period>` | Время хранения файла: число и единица `s`, `m`, `h` или `d` (секунды, минуты, часы, дни), например `30m`, `12h`, `7d`. По умолчанию файл хранится бессрочно |
| `-n`, `--max-downloads <count>` | Сколько раз можно скачать файл: положительное число. По умолчанию число скачиваний не ограничено |
| `-p`, `--password` | Защитить файл паролем. Пароль запрашивается при выполнении команды, дважды |
| `-s`, `--server <url>` | Адрес сервера для этой команды |

## download

Скачать файл.

```
mayfly download <id> [опции]
```

### Аргументы

| Аргумент | Описание |
|---|---|
| `id` | Идентификатор файла |

### Опции

| Опция | Описание |
|---|---|
| `-o`, `--output <path>` | Путь, по которому сохранить файл, или каталог, в который сохранить его под своим именем. По умолчанию имя файла в текущем каталоге |
| `-f`, `--force` | Перезаписать файл, если он уже существует |
| `-s`, `--server <url>` | Адрес сервера для этой команды |

## completion

Вывести скрипт автодополнения команд и опций по Tab.

```
mayfly completion <shell>
```

### Аргументы

| Аргумент | Описание |
|---|---|
| `shell` | Оболочка: `bash`, `zsh` или `powershell` |

### Подключение

Выполнить один раз, затем открыть новый терминал.

bash:

```bash
echo 'eval "$(mayfly completion bash)"' >> ~/.bashrc
```

zsh:

```zsh
echo 'eval "$(mayfly completion zsh)"' >> ~/.zshrc
```

PowerShell:

```powershell
Add-Content $PROFILE 'mayfly completion powershell | Out-String | Invoke-Expression'
```
