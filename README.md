# Mayfly

Сервис для обмена файлами: загрузите файл, получите его идентификатор и передайте тому, кто должен файл скачать.

## Возможности

- Загрузка и скачивание файлов по идентификатору.
- Срок хранения: файл хранится бессрочно или становится недоступен в заданный момент.
- Защита паролем: без пароля такой файл нельзя ни скачать, ни посмотреть сведения о нём.
- Ограничение числа скачиваний: после последнего разрешённого скачивания файл становится недоступен.

## Состав

| Часть | Расположение | Описание |
|---|---|---|
| Сервер | `src/Server` | HTTP API, см. [docs/api.md](docs/api.md) |
| Консольное приложение | `src/Terminal` | Команда `mayfly`, см. [docs/terminal.md](docs/terminal.md) |
| Клиентская библиотека | `src/Client` | Пакет `Mayfly.Client` для .NET-приложений |
| Веб-интерфейс | `src/Browser` | Страница для отправки и скачивания файлов, образ `ghcr.io/chikovmf/mayfly-browser` |
