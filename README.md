# Mayfly

Сервис для обмена файлами: загрузите файл, получите его идентификатор и передайте тому, кто должен файл скачать.

## Возможности

- Загрузка и скачивание файлов по идентификатору.
- Срок хранения: файл хранится бессрочно или становится недоступен в заданный момент.
- Защита паролем: без пароля такой файл нельзя ни скачать, ни посмотреть сведения о нём.
